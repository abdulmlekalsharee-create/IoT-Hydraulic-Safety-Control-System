# 🌊 Autonomous IoT-Based Hydraulic Monitoring and Safety Control System

## 📌 Project Overview
In modern fluid distribution networks, undetected leakages and uncontrolled pressure surges constitute a major cause of infrastructure failure. This project presents the design and implementation of a robust Smart Water Management System powered by the ESP32 Dual-Core Microcontroller. By integrating Industrial 4-20mA sensing standards with Consumer IoT protocols, the system creates a "Digital Twin" of the hydraulic network, bridging the gap between domestic plumbing and Industry 4.0.

## ⚙️ Hardware Architecture & Component Selection
The hardware selection prioritized accuracy, noise immunity, and a fail-safe mechanical design:
- **Microcontroller:** ESP32 DevKit V1 (Dual-Core for simultaneous sensor processing and web hosting).
- **Industrial Pressure Sensor:** 0-4 Bar, 4-20mA current loop standard (chosen for immunity to voltage drops and electrical noise over long wires).
- **Flow Sensor:** YF-S201 (Hall-Effect principle).
- **Actuator:** 12V Normally Closed (NC) Solenoid Valve (acts as a mechanical fail-safe in case of power loss).
- **Display & Feedback:** 1.3" OLED (SH1106) and Active Buzzer.

### ⚡ Dual-Rail Power Strategy
To ensure system stability and prevent the ESP32 from crashing due to Back-EMF generated by the solenoid valve, a dual-rail power distribution was implemented:
- **"Dirty" Rail (5V via Buck Converter):** Supplies the Relay Coil and Solenoid Valve.
- **"Clean" Rail (3.3V via LDO Regulator):** Supplies the ESP32 and I2C OLED Display.

## 🧮 Mathematical Modeling & Fluid Mechanics
The system translates raw sensor data into meaningful hydraulic parameters using fundamental physics:

**1. Flow Rate & Velocity:**
The continuity equation is applied to determine fluid velocity $v$ inside the pipe:
$$v = \frac{Q}{A}$$

**2. Bernoulli’s Principle (Energy Conservation):**
The system monitors the energy state of the fluid. Anomaly detection algorithms look for sudden pressure drops correlating with velocity spikes, indicating potential pipe ruptures:
$$P + \frac{1}{2}\rho v^2 + \rho g h = \text{Constant}$$

**3. Hydraulic Power:**
Calculates the energy power transmitted by the fluid:
$$P_{hyd} = P \times Q$$

## 🚀 Tri-Mode Control Logic
1. **Manual On-Site Control:** Direct operation via breadboard push buttons for offline usability.
2. **Remote Web-Based Telemetry:** An Asynchronous Web Server allows control and monitoring via any smartphone browser.
3. **Autonomous AI Logic:** - *Over-Pressure Protocol:* If Pressure > 3.5 Bar, the system overrides user commands and AUTO-CLOSES the valve.
   - *Leak Detection Protocol:* Triggers an alarm if flow is detected while the valve is logically closed.
